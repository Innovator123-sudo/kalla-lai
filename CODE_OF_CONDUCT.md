# Code of Conduct

## Our pledge

We want a community where anyone can contribute without harassment, and where disagreement about code stays about the code. Everyone participating in this repository — issues, pull requests, discussions and reviews — is expected to help make that true.

## Expected behaviour

- Be respectful, patient and constructive.
- Assume good intent; ask before assuming a mistake is careless.
- Give specific, actionable feedback and accept it gracefully in return.
- Respect that contributors have different backgrounds, languages, time zones and levels of experience.
- Protect user privacy. Never share real user data, credentials or identity documents in issues, logs or screenshots.

## Unacceptable behaviour

- Harassment, insults, discrimination or personal attacks.
- Sexualised language or imagery, and unwelcome sexual attention.
- Publishing someone's private information without consent.
- Threats, intimidation, or sustained disruption of discussions.
- Deliberately introducing malicious code, backdoors or data exfiltration.

## Scope

Applies to all project spaces — the repository, issues, pull requests, discussions, the public website's contact flow, and any project-related communication — and to anyone representing the project in public.
